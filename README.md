# 🦷Camila | Odontologia

Landing page personalizada desenvolvida para **Camila Marques Novais**, estudante de Odontologia, com o objetivo de registrar sua trajetória acadêmica e suas primeiras experiências profissionais.

🔗 **[Ver site publicado](https://laryssasouzacs.github.io/landingpage-odonto/)**

## Sobre o projeto

Camila é minha amiga e, durante uma conversa sobre sua graduação e as experiências que vem vivendo na Odontologia, decidimos transformar essas informações em uma landing page personalizada.

A ideia foi criar um pequeno portfólio pessoal para registrar sua trajetória acadêmica até aqui, reunindo um pouco sobre sua graduação, áreas de interesse e experiências vivenciadas durante o estágio.

A página foi construída com foco em:

- **Personalização:** conteúdo baseado nas experiências reais e na trajetória da Camila
- **Identidade visual:** design minimalista e acolhedor, pensado para transmitir uma apresentação pessoal
- **Hierarquia visual:** organização das informações em seções que acompanham sua jornada
- **Responsividade:** adaptação do layout para diferentes tamanhos de tela

## Tecnologias

- HTML5 semântico
- CSS3
- CSS Grid
- Flexbox
- Google Fonts

Projeto desenvolvido sem frameworks ou bibliotecas de JavaScript, utilizando HTML e CSS puros.

## Estrutura da página

A landing page está dividida em três seções principais:

- **Sobre:** breve apresentação da Camila e suas áreas de interesse dentro da Odontologia
- **Jornada:** alguns momentos e etapas de sua trajetória durante a graduação
- **Estágio:** experiências práticas e atividades desenvolvidas durante o estágio

## Responsividade

O layout foi desenvolvido para se adaptar a diferentes tamanhos de tela.

Foram realizados ajustes específicos para dispositivos móveis, incluindo:

- reorganização das seções em uma única coluna
- adaptação do tamanho das tipografias
- reposicionamento da imagem da seção Sobre
- ajuste da Jornada para telas menores
- reorganização do footer
